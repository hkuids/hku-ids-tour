Hide the bottom / device holder

A higher value hides more of the floor. Markers below the limit move into the visible area so walking still works. This stops looking down in the tour; a permanent cover in the upload JPGs also protects the original files.

WordPress picture addresses

Upload the prepared WordPress batch into one folder/month. Copy a full-size original image URL, then apply its folder here. If WordPress renamed a file, use its individual direct URL above. Pictures stored on a different website must allow this tour to load them.

Import / export

Preview edits stay in this browser. Download route.json, upload it to the GitHub repository, commit, wait for the green Actions result, and reload the tour. GitHub is the shared configuration; sending a settings file to the assistant is optional.

Download a backup first if you want to keep your browser edits.
