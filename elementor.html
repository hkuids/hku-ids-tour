Add the tour to your WordPress page

You only need Elementor’s HTML widget. This block displays the hosted tour, including its pictures, controls and future branches.

  1. In wp-admin, open Pages and select your visitor-guide page.
  2. Choose Edit with Elementor.
  3. Drag an HTML widget into a full-width area of the page.
  4. Copy the block below and paste it into the widget.
  5. Click Update or Publish. Open the actual page in a private/incognito window and try the lift and P3 choices.

WordPress will store the prepared pictures; GitHub Pages or another host can serve the tour software. Later branches appear through the same embed address.

Use the public tour’s address after hosting is ready. For this tour, use https://hkuids.github.io/hku-ids-tour/.

Your pictures in WordPress Media Library

Media Library can store the panorama pictures, but uploading pictures alone does not create the linked tour. The current tour is already configured with their original direct image URLs. Future picture batches will also need their URLs added to the tour settings. The prepared WordPress picture batch uses unique filenames. Upload the batch, copy the original file URL of one picture, and enter it under WordPress picture addresses in the configuration console. Download route.json to publish those addresses.

Our pictures are 4096 × 2048. WordPress normally generates a smaller “scaled” copy for images above 2560 pixels; use the original panorama file to keep the detail. A cropped thumbnail will not work as a full 360° picture.

Other image storage

A department file server or an image/object-storage service can also host them. It needs direct image URLs and must allow the WordPress page to load the pictures. Gallery and sharing-page links are not the image files the viewer needs.
